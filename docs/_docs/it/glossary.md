| Termine | Significato |
|---|---|
| **Abbandono (churn)** | agenti che lasciano la piattaforma per inattività o stress |
| **Archetipo** | `validator`, `broadcaster` o `explorer`: una riduzione del menu di azioni |
| **Barriera** | il punto in cui il server aspetta ogni client attivo prima di far avanzare uno slot |
| **Client** | il processo che ospita gli agenti e decide che cosa fanno |
| **Confidenza limitata** | modello di opinione: si attraggono solo opinioni più vicine di `epsilon` |
| **Downcast** | forzare validator ed explorer a un comportamento a regole |
| **Agente pagina** | un agente che rappresenta una testata e condivide solo link |
| **Finestra di attenzione** | slot di storico che contano ancora per gli interessi di un agente (336 per default) |
| **Heartbeat** | il segnale periodico che mostra che un client è vivo |
| **Profilo di attività** | un elenco con nome di ore in cui un agente è disponibile |
| **Raccomandatore** | l'algoritmo che costruisce un feed (contenuti) o suggerisce account (follow) |
| **Round / slot** | un'ora simulata; una riga di `rounds` |
| **Server** | l'attore Ray che possiede orologio, database e raccomandatori |
| **vLLM** | motore locale di modelli ad alto throughput con inferenza a batch |
